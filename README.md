# 愉悦 · 个人生活管理工作台

一个纯前端、零后端、数据本地存储的个人生活管理工具。一个 HTML 文件搞定所有功能，手机「添加到主屏幕」即可当 App 使用。

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 工作台主程序，所有模块都在这里 |
| `xlsx.full.min.js` | Excel 导出依赖（与 index.html 同目录） |

> 数据全部存在浏览器 `localStorage`，**不会上传任何服务器**，隐私安全。

## 已内置模块

| 模块 | 功能 |
|------|------|
| 🌸 今日概览 | 一眼看今天待办进度、记账、阅读、英语词汇 |
| ✅ 每日任务看板 | 每日待办、勾选打卡、进度条（可切换日期） |
| 💰 记账模块 | 手动记账 + 餐饮/交通/购物/住房/娱乐/医疗/教育等分类 + 月度占比 |
| ⏳ 重要日期倒计时 | 生日/考试/纪念日提醒，自动算剩余天数 |
| 📚 阅读打卡 | 书架管理 + 每日打卡 + 30 天热力图 |
| 🗣️ 英语学习模块 | 口语表达积累 / 词汇学习+自测 / 外刊精读 / 演讲金句 |
| 🧠 知识库模块 | 知识整理 + 重点总结 + 一键生成试卷自测 |
| 💡 小tips模块 | 小技巧收集、标签分类、可视化、模糊搜索 |
| 📝 每日总结模块 | 生活/工作/感悟总结 + 周/月/年自动汇总 + 横向对比 |

所有模块**名称可自定义、可开关**（见左下角「⚙️ 模块设置」）。

## 本地使用

直接用浏览器打开 `index.html` 即可。建议用 Chrome / Edge / Safari。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `yuyue`）。
2. 把 `index.html` 和 `xlsx.full.min.js` **两个文件一起**上传到仓库根目录。
3. 进入仓库 `Settings → Pages`，Source 选择 `Deploy from a branch`，分支选 `main`（或 `master`），目录选 `/ (root)`，保存。
4. 等待一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 注意：必须两个文件在同一目录，否则 Excel 导出按钮会提示「xlsx 库未加载」。

## 手机添加到主屏幕（当 App 用）

- **iPhone (Safari)**：打开页面 → 点击底部「分享」→「添加到主屏幕」→ 命名「愉悦」→ 完成。之后从桌面图标进入即为全屏 App 体验。
- **Android (Chrome)**：打开页面 → 右上角「⋮」→「添加到主屏幕」→ 确认。
- 首次使用建议先添加几条数据，体验各模块。

## 数据备份与恢复

- 左下角「📤 导出备份」：导出全部数据为 JSON 文件（换设备/清缓存前务必备份）。
- 左下角「📊 导出Excel」：把待办、记账、单词、总结、tips 导出为 `.xlsx` 表格。
- 左下角「📥 导入备份」：选择之前的 JSON 文件即可恢复。

## 小贴士

- 清浏览器缓存或卸载会丢失 `localStorage` 数据，重要数据记得定期导出备份。
- 各模块右上角「⚙️ 模块设置」可隐藏不用的模块、重命名模块。
